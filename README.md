# FairFight Website

A small Flask website for FairFight focused on inclusive design, technology, and community impact.

## Local setup

1. Create and activate a virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the app:
   ```bash
   python app.py
   ```
4. Open http://localhost:5000 in your browser.
