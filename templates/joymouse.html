Meet JoyMouse.

A software-based, hands-free computer interaction system powered by computer vision.

What is JoyMouse?

JoyMouse is designed to enable computer interaction without relying on conventional hand-operated input devices.

Face Tracking

Computer vision tracks facial movement to control interaction.

Adaptive Joystick

An adaptive interaction architecture translates movement into cursor control.

Gesture Interaction

Facial gestures can be used to trigger computer actions.

Software Based

Designed around commonly available computing hardware and cameras.
